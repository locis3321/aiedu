# 等差数列求和（首尾配对）

## 核心思想
从 a1 起每次加 d 共 n 项：末项 an=a1+(n−1)d；和=(a1+an)×n÷2（首尾相等配对）。

## 使用条件
- 已知首项、公差、项数（等差、整数项）。

## 特有误差
- 末项漏乘 (n−1)（把第 n 项算成 a1+n×d）。
- 配对后忘记 ÷2。

## 一句话
首尾相加相等，共 n 对，和=(首项+末项)×n÷2。
