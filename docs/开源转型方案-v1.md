## 0. 为什么转（审查结论 → 转型收益对照）

| 审查根因 | C 端产品形态下 | 开源引擎形态下 |
|---|---|---|
| RC1 无垂直切片（前端零 API 调用、发布 409 硬门、无 LLM 即死） | 致命 | **转化为轻量目标**：`uvx 启动 → tool call 成功` 即垂直切片 |
| RC2 承载形态法律死锁（个人主体不可配业务域名、教培定向准入） | 致命 | **消失**：合规责任转移给调用方（agent 宿主/集成者） |
| RC3 投入倒挂（治理 3635 行 > 教学 2346 行；文档 321MB vs 代码 1.9MB） | 结构性 | **自然解决**：MCP 只暴露核心能力，C 端外围域整体出局 |
| RC4 46 功能点超量、P0 失效 | 结构性 | **自然解决**：工具面收敛为 4~5 个 tool |
| RC5 不可验证护栏 + 反迭代流程 | 持续阻力 | **大幅缓解**：以 API 契约与 CI 断言为准 |
| RC6 无付费者却扛全部合规成本；"先想后看"已非差异点 | 致命 | **重新成立**：2026 年 MCP 生态中无任何"数学核验+教学门禁+答案门控渲染"服务（已核实：math-mcp-learning-server=计算器、EduChain=出题器、SymKit=符号计算、其余为 LMS 集成） |

**保留的真实资产**（审查实测确认真实可用）：SymPy 受限 AST 核验（168 行）、answer-filtered 先想后看服务端过滤、教学政策门禁、LessonSpec v2 契约 + player（Playwright 9/9）、run_pipeline 六阶段（零 LLM 可跑 make_ten）。

**必须诚实面对的硬伤**（转型后不消失、反而暴露更快）：零 LLM 确定性出课覆盖面 = 1 个知识点（make_ten）。开源前必须扩到 ≥3 个，且 `verify_math` 覆盖面必须超出凑十法算式。

## 1. 新定位

- **产品名（工作名）**：`aiedu-core`（库）/ `aiedu-mcp`（服务）/ `aiedu-player`（渲染器）
- **一句话**：给 AI Agent 的"数学可信教学引擎"——输入一道题，输出**经过独立数学核验的、答案门控的（先想后看）、可交互渲染的课程规格**。
- **差异点（在 MCP 生态内的空白）**：
  1. **数学核验而非生成**：LLM 只解释，SymPy 判定；`verified` 附核验凭据（verifier_version + claims + content_hash）；
  2. **先想后看作为 API 语义**：`get_lesson(answer_filtered=true)` 在孩子尝试前不返回答案字段——竞品的"家长模式"做不到服务端强制；
  3. **可交互渲染出口**：`render_lesson(spec)` 返回可分享 URL，agent 不必自己实现课堂 UI——这是纯计算类 MCP 完全没有的能力。
- **不宣称**：不宣称覆盖 K12 数学路线（当前能力=3 个知识点）；不宣称"已掌握/掌握度百分比"；不内置未成年合规（README 明示由集成方承担）。

## 2. 仓库重组（从 projects/ monorepo 到三层包）

```text
aiedu/
├── packages/
│   ├── aiedu-core/            # pip 库（依赖仅：sympy + pydantic + httpx[可选]）
│   │   ├── intent/            # 规则意图识别（现 app/intent，273 行）
│   │   ├── verify/            # SymPy 受限 AST 核验 + 核验凭据（现 app/services/sympy_verify 等）
│   │   ├── skills/            # skill 加载/检索（只读不执行）
│   │   ├── strategies/        # 确定性出课模板：make_ten / borrow_ten / fraction_equal_parts
│   │   ├── policy/            # 教学政策门禁（BLOCKER/MAJOR/MINOR）
│   │   ├── pipeline/          # run_pipeline 六阶段（LLM 可选：有 key 用受控设计，无 key 走确定性模板）
│   │   └── spec/              # LessonSpec v2 pydantic 契约 + 语义校验
│   ├── aiedu-mcp/             # MCP server（FastMCP；依赖：fastmcp + aiedu-core）
│   │   ├── server.py          # stdio + HTTP 双传输
│   │   └── tools.py           # 4~5 个 tool（见 §3）
│   └── aiedu-player/          # 现有 player 迁入（TS + GSAP，Playwright 9/9）
│       └── render service     # spec → 静态可分享课堂 URL（FastAPI StaticFiles 或独立小服务）
├── teaching-skills/           # Claude-style skill 包（SKILL.md 格式，直接可被 agent 生态安装）
├── examples/                  # Claude Code / OpenCode / WorkBuddy / Claude Desktop 接入配置示例
└── docs/                      # 本方案 + 审查报告 + 最小规范（≤2 页）
```

**退出主仓（封存到 `archive/` 分支或目录，不删除历史）**：
accounts、sms、points、questionbank、reports、admin_api、profile、jobs/outbox/Celery、workers、storage/artifacts(S3)、observability(OTel)、miniprogram、admin(Web)、h5-lesson-spike、infra(PG/Redis/MinIO/Tempo/Grafana)、Alembic 11 迁移、5 张零引用表、6 组循环依赖中的外围环。

**依赖目标**：aiedu-core = 3 个直接依赖（sympy/pydantic/httpx 可选）；全仓 .venv 从 372MB → ~60MB；运行 = 0 容器 1 进程。

## 3. MCP 工具面（只做这 5 个，禁止加）

| Tool | 输入 → 输出 | 复用的现有实现 |
|---|---|---|
| `verify_math` | expression, expected → {verified, claims, credential} | sympy_verify + 受限 AST 白名单 |
| `generate_lesson` | question, age?, skill_hint? → LessonSpec v2（LLM 可选） | run_pipeline 全链路 |
| `get_lesson` | spec_id, reveal: "filtered"\|"full" → 答案门控的课程数据 | answer-filtered（`_filtered_spec`，本项目最好的实现） |
| `submit_attempt` | spec_id, node_id, answer → {correct, hint_ladder, evidence} | `_judge` + 证据分级（降为两级：independent/assisted） |
| `render_lesson` | spec → {url}（可交互课堂页，48px 触控、一屏一任务） | player + StaticFiles |

配套发布：`prompts`（math_tutor 引导提示词）与 `resources`（teaching-skills 目录、LessonSpec v2 schema 文档）。

**先想后看语义在 MCP 层的体现（护栏 1 的新载体）**：`get_lesson(reveal="filtered")` 返回的 spec 中，未解锁节点的 `response.expected` 必须为 null——**一条 CI 断言守住整个护栏**（替代原 536 行规范中不可自动验证的部分）。

## 4. 范围与护栏的映射调整

| 原 13 条护栏 | 开源引擎形态下的处置 |

## 8. 决策更新（2026-10-21 · 主理人终审，无界面运行形态 v1）

> 结论摘自《产品增量-无界面管理面-v1.md》与《架构增量-无界面运行形态-v1.md》（决策 §6）；两者已按文档纪律移入 `docs/memory/`。执行清单：`docs/memory/2026-10-21-工程师执行清单-无界面运行形态-v2.md`。

1. **鉴权三档**：(a) 本地 stdio 零 token；(b) 自建 HTTP `AIEDU_AUTH_TOKEN` 静态 Bearer（未设置=不启用）；
   (c) 托管演示档（现在就做）= **自服务注册制拿 token**（`POST /register` + `/revoke`，无账号概念、
   仅可选昵称、明文仅显示一次、只存 SHA-256 哈希）+ 网页 demo 页匿名一次性试用（IP 限流）。
   远程 MCP 端点 = 主形态；`/register` `/revoke` 是 HTTP route，**不是第 6 个 MCP tool**（工具面冻结保持）。
2. **配额**（per-token）：generate ≤20/h、≤300/月；verify ≤200/h；get/submit ≤500/h；render ≤200/h；
   匿名试用 generate ≤10/h/IP；全局日熔断 ≤20,000；runaway >60 generate/h → rate_limited；
   **capability_gap 全局语义不变**；限流只拦 tools/call（initialize/list 不受限）。
3. **分享双模式**：默认自习课堂（full URL，交互层门控"答对才推进"）；无答案预览（filtered URL +
   player 降级横幅，作答不判定）。`render_lesson` **不加模式入参**（spec 形态即模式声明）。
   teaching-skills 分享三句话话术，逐字见 SKILL.md；禁止 Agent 为防偷看删改 spec。
4. **render_lesson 本地拼 URL**：`AIEDU_PLAYER_URL` → `AIEDU_PUBLIC_URL`(拼 /player) → 请求推导 →
   兜底常量；`player_unavailable` 错误类型消亡；`AIEDU_PLAYER_TIMEOUT` 弃用。player 静态托管同域挂载
   （`AIEDU_SERVE_PLAYER=1` + `--host`）。
5. **引擎红线**：演示档 + LLM env + 无 token = **启动硬拒绝**；sqlite3/secrets/hmac/contextvars 等
   全为标准库，零新增运行时依赖；player 仍 gsap-only；工具面冻结（5 个 tool 不变）。
6. **商业化透明**：永久开源 + 功能等价承诺；商业版只卖运维面；License Apache-2.0 不变；
   数据透明（token/IP 仅哈希，不留原文、不画像、不收集未成年人数据）。
